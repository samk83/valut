작동 방식

들어오기만 하고,
나가지 않는 금고.

스크롤을 내리면 금고를 만드는 순간부터 마지막 잠금까지, 앱이 실제로 하는 일을 순서대로 보여드립니다.

금고를 만듭니다.

가입도 이메일도 없습니다. 숫자 PIN이나 패턴 하나로 이 휴대폰 안에 금고가 생깁니다. 대신 복구 방법이 없다는 점에 먼저 동의해야 합니다.

Argon2idSecure EnclaveStrongBox

사진첩에서
금고로 옮깁니다.

고른 사진과 동영상을 파일마다 다른 키로 암호화하고 다시 풀어서 확인합니다. "가져온 뒤 원본 삭제"를 켜 두었다면 그 확인이 끝난 뒤에야 원본 삭제를 요청합니다. 중간에 실패하면 원본은 그대로 남습니다.

찍는 순간부터
금고 안에.

금고 카메라로 찍은 사진과 영상은 사진첩에 저장되지 않습니다. 영상은 녹화하는 동안 조각 단위로 암호화되고, 위치 정보는 지워집니다.

사진첩 저장 안 함위치 정보 제거

05 / 06

앱 안뿐입니다.

공유, 내보내기, 저장, 인쇄 버튼이 아예 없습니다. 앱을 벗어나면 바로 잠기고, 앱 전환 화면에도 내용이 보이지 않습니다.

내보내기 없음즉시 자동 잠금

보안 기술

열쇠가 두 개 있어야
열리는 문.

금고를 여는 마스터키는 당신의 PIN과 휴대폰 보안칩, 두 가지가 모두 있어야 만들어집니다. 둘 중 하나만으로는 열 수 없고, 풀린 마스터키는 금고가 열려 있는 동안에만 메모리에 두고, 잠기면 지웁니다.

당신이 아는 것PIN 또는 패턴Argon2id로 1회 확인에 약 1초가 걸리도록 설정해(목표치) 대입 공격을 늦춥니다.

+

휴대폰이 가진 것보안칩 키iPhone은 Secure Enclave, Android는 StrongBox. 칩 밖으로 꺼낼 수 없습니다.
MASTER KEY마스터키두 열쇠가 모두 있을 때만 풀립니다. 잠기면 메모리에서 지웁니다.
PER-FILE KEY파일별 키사진 한 장, 영상 하나마다 서로 다른 키를 씁니다.
AES-256-GCM암호화된 파일사진·영상은 물론 파일 이름, 촬영 정보, 썸네일까지 암호화합니다.

세 번 틀리면 키 파기

3 attempts → key destruction

시도 횟수는 PIN을 확인하기 전에 먼저 기록됩니다. 확인 도중 앱을 강제로 꺼도 횟수가 줄지 않습니다.

인터넷을 쓰지 않습니다

no network permission

Android 앱에는 인터넷 권한이 아예 없습니다. 서버, 계정, 클라우드, 광고·분석 도구가 없고 비행기 모드에서도 모든 기능이 작동합니다.

들어오기만 하는 금고

one-way import

공유, 내보내기, 다른 앱으로 열기 기능이 코드에 없습니다. 금고에 들어온 파일은 앱 안에서만 볼 수 있습니다.

금고 전용 카메라

in-vault camera

찍은 사진은 사진첩을 거치지 않습니다. 영상은 녹화 중 조각마다 따로 암호화되어, 평문 파일이 저장 공간에 남지 않습니다.

다시 설치해도 열리지 않습니다

device-only keys

키는 백업과 기기 이전에 포함되지 않는 등급으로 저장됩니다. 앱을 지웠다 다시 깔면 이전 금고가 아닌 새 금고가 만들어집니다.

동영상도 조각마다 검증

chunked AES-GCM streaming

영상은 재생할 부분만 조금씩 풀어 메모리에서 보여줍니다. 조각마다 인증 태그가 있어 순서를 바꾸거나 잘라내면 재생을 멈춥니다.

알아두실 점

강한 금고에는
분명한 한계도 있습니다.

PrivateVault는 해킹을 원천 차단한다고 말하지 않습니다. 무엇을 지켜 주고, 무엇은 지켜 주지 못하는지 먼저 알려드립니다.

복구 방법이 없습니다

PIN을 잊거나, 휴대폰을 잃어버리거나, 앱을 지우면 파일을 다시 열 수 없습니다. 저희도 열어 드릴 수 없습니다.

탈옥·루팅된 기기

3회 제한은 정상 기기에서 지켜집니다. 탈옥·루팅된 기기나 전문 포렌식 장비를 가진 공격자는 이 제한을 우회할 수 있습니다. 그런 환경이 감지되면 금고 열람을 막고, PIN은 10자리 이상을 권장합니다.

금고가 열려 있는 동안

금고가 열린 순간 휴대폰 자체를 장악당하면 어떤 앱도 막을 수 없습니다. 다 본 뒤에는 바로 잠그세요.

다른 곳에 남은 사본

사진첩의 '최근 삭제된 항목'과 클라우드 사진 백업에 남은 사본은 직접 지워야 합니다. 앱은 가져오기가 끝나면 이 점을 알려 드립니다.
